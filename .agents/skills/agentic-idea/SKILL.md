# Agentic Idea

## Process

1. Restate as a How Might We.
2. 3–5 sharpening questions (who, success metric, hard constraint, why now).
3. 2–3 distinct directions. Stress-test: painkiller vs vitamin, feasibility, time-to-value.
4. Assumption audit: Must / Should / Might.
5. Write `.agentic/journal/idea-<slug>.md`: problem, direction, MVP, **Not Doing**, open questions.
6. Do not overwrite that file if it still has unchecked open questions, unless the user says to.
7. `/agentic-task` for the MVP slice only.

## Rationalizations

| Excuse | Rebuttal |
|---|---|
| I'll just start coding the obvious version | That's a silent direction choice. Write Not Doing first. |

## Verification

The 1-pager exists; Not Doing is non-empty; a lite or full ticket points at it.
